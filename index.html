Custom PIDs

This is how you add manufacturer-specific (enhanced) variables — transmission fluid temp, CVT pulley pressures, VVT angle, and so on. You supply the request and a formula; the variable then shows up in the picker like any other.

New custom variable

Formulas accept numbers, A–H, + − × ÷, parentheses, and s8(), s16(), min(), max(), abs(). Values should be in the unit you typed above. Example: (A*256+B)/10-40. For requests like 2101 the module's echo bytes are stripped for you, so A is the first real data byte.

About BayScope

A single-page OBD-II dashboard for Toyota, Nissan, and generic vehicles. It talks to a Bluetooth LE ELM327-compatible adapter through Web Bluetooth, so it needs Chrome or Edge (desktop) or Chrome on Android, over HTTPS.

Read this before trusting it in a car. The standard-PID read path, the supported-PID scan, the VIN / readiness read, and the code reader are implemented but were written without access to a physical adapter. Try it on a parked car first and compare against a known-good tool. Anything marked est. or unverified is an estimate or unconfirmed on real vehicles.

Simulation mode generates plausible data with no car attached — everything it shows is fake, and exports from it are labelled as such.
